# 作物知识智能查找与匹配平台 PRD

## 1. 产品概述

本产品把《课程设计资料.pdf》中的扫描版作物资料整理为可查询、可维护的结构化知识库，服务普通注册用户和管理员。第一版以稳定的结构化检索为核心，后续增加 OCR/AI 辅助录入和自然语言查询。

## 2. 用户与问题

### 普通用户

用户需要按照作物名称、科属、分布、用途、含油率和化学组分快速找到目标作物，并查看完整资料和图片。

### 管理员

管理员需要录入、审核、修改和删除作物资料，维护别名、样品、化学数据和图片。

### 当前问题

- 资料主要存在于扫描 PDF 中，无法直接检索。
- 同一作物可能有中文名、英文名、拉丁学名和多个别名。
- 文字资料与化学数据表分散，难以组合筛选。
- 图片、样品来源和检测结果需要保持对应关系。

## 3. 产品目标

1. 完成 PDF 资料的结构化整理和来源追踪。
2. 支持单条件、组合条件和数值范围查询。
3. 允许用户选择查询结果字段。
4. 提供管理员审核和维护流程。
5. 为后续 OCR、自然语言检索和知识问答预留数据接口。

## 4. MVP 范围

### 包含

- 注册、登录、退出和角色权限。
- 作物基本资料、别名、图片、样品和检测数据管理。
- 按名称、科、属、分布、用途等文本条件查询。
- 按含油率、碘值、酸值、皂化值和脂肪酸含量查询。
- 全部条件或任意条件组合查询。
- 查询字段选择、分页和详情展示。
- 管理员增删改和数据审核。

### 后续增强

- OCR/AI 字段抽取。
- 自然语言查询条件解析。
- 基于结构化资料的问答。
- 相关作物推荐和外部资料链接。

## 5. 主要用户流程

### 普通用户

注册 → 登录 → 输入查询条件 → 选择结果字段 → 查看结果 → 查看作物详情。

### 管理员

登录 → 进入后台 → 新增或审核资料 → 维护图片和检测数据 → 发布到前台查询。

## 6. 功能需求

### FR-01 用户账户

注册时校验用户名唯一、密码一致、邮箱格式和必填项；登录后根据角色控制功能入口。

### FR-02 作物查询

支持中文名、英文名、拉丁学名、别名、科、属、特征、分布、栽培和用途查询；文本字段支持模糊匹配。

### FR-03 数值查询

支持含油率、碘值、酸值、皂化值和化学组分的等于、大于、小于和范围查询。

### FR-04 组合查询

多个条件可以按“全部满足”或“任意满足”组合，空条件不参与过滤。

### FR-05 结果展示

用户可以选择显示字段；结果支持分页，点击作物进入详情页，详情页展示来源、图片、样品和检测数据。

### FR-06 管理维护

管理员可以维护作物、别名、图片、样品、油脂指标和化学组分；删除操作需要二次确认。

### FR-07 数据审核

导入或 AI/OCR 提取的数据先进入待审核状态，管理员审核通过后才进入正式查询结果。

## 7. 非功能要求

- 普通查询目标响应时间不超过 2 秒。
- 后端使用参数化 SQL，避免 SQL 注入。
- 密码不得明文保存。
- 所有资料记录 PDF 来源页码。
- 图片限制格式和大小，文件名由系统生成。
- 页面兼容桌面浏览器，并完成基本表单提示和无结果提示。

## 8. 验收标准

- 用户可以注册并登录，普通用户不能访问管理员页面。
- 管理员新增的作物可以被前台查询。
- 至少三个条件同时查询时，结果逻辑正确。
- 含油率和化学组分范围查询结果正确。
- 用户可以自定义结果字段。
- 作物详情能够关联正确图片、来源页码和检测数据。
- OCR/AI 提取数据必须经过审核后才展示。

## 9. 产品指标

| 指标 | 目标 |
|---|---:|
| 资料结构化完成率 | 100% |

| 组合查询正确率 | ≥95% |
| 普通查询响应时间 | ≤2 秒 |
| 管理员录入时间降低 | ≥50% |
