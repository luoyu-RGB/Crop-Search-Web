# 详细开发阶段计划

本文件补充最终计划书中的具体开发内容、阶段产出、验收标准和 Git 检查节点。

## 第一阶段：产品调研和需求分析

### 开发内容

- 分析《课程设计资料.pdf》的页面结构、字段和数据类型。
- 明确普通用户、管理员和资料审核人员的使用场景。
- 确定 MVP 功能和后续 AI 功能边界。
- 编写 PRD、用户流程、功能清单和验收标准。
- 编写数据库数据字典。

### 阶段产出

- 产品需求文档。
- 用户流程图和业务流程说明。
- 数据字典。
- 页面功能清单。
- 阶段记录。

### 验收标准

- 核心字段已经确认。
- 用户权限边界已经确认。
- 数据库实体关系已经确认。

### Git 节点

用户检查通过后提交第一阶段版本。

## 第二阶段：数据库和项目基础搭建

### 开发内容

- 初始化 Git 仓库。
- 创建 Maven Java Web 项目。
- 配置 Servlet、JSP、JDBC、MySQL 和 Tomcat 基础依赖。
- 编写数据库建表脚本。
- 创建项目目录结构、首页和 `web.xml`。
- 编写数据库初始化说明。

### 阶段产出

- `pom.xml`。
- `database/schema.sql`。
- `database/seed.sql`。
- Java Web 项目骨架。
- 基础首页。

### 验收标准

- Maven 可以成功打包 WAR 文件。
- 数据库脚本可以创建全部核心表。
- 项目结构可以被 Tomcat 识别。
- 构建目录不进入 Git。

### Git 节点

用户检查通过后提交第二阶段版本。

## 第三阶段：注册、登录和权限控制

### 开发内容

- 创建 User JavaBean、DAO、Service 和 Servlet。
- 实现注册、登录和退出。
- 使用 Session 保存登录状态。
- 创建字符编码、登录和管理员权限 Filter。
- 使用 JavaScript/jQuery 完成表单验证。

### 验收标准

- 用户名重复时不能注册。
- 密码不一致时不能提交。
- 未登录用户不能访问受限页面。
- 普通用户不能访问管理员页面。
- 密码不以明文保存。

### Git 节点

完成功能测试并经用户检查后提交第三阶段版本。

## 第四阶段：作物资料查询

### 开发内容

- 创建作物、别名、样品和检测数据实体类。
- 实现名称、科、属、分布、用途等文本查询。
- 实现含油率、碘值、酸值、皂化值和化学组分查询。
- 实现多个条件的全部满足和任意满足逻辑。
- 实现分页、结果字段选择和作物详情展示。
- 关联作物图片、样品信息和 PDF 来源页码。

### 验收标准

- 三个以上条件组合查询结果正确。
- 空条件不会影响有效条件。
- 数值范围查询结果正确。
- 详情页显示正确图片和检测数据。
- 无结果时显示明确提示。

### Git 节点

查询功能通过测试和人工检查后提交第四阶段版本。

## 第五阶段：管理员资料维护

### 开发内容

- 实现作物新增、修改和删除。
- 实现别名、样品、产地和检测数据维护。
- 实现图片上传、删除和封面设置。
- 实现 PDF 来源页码和审核状态管理。
- 实现删除确认、异常提示和操作记录。

### 验收标准

- 管理员新增数据可以被前台查询。
- 修改后前台显示最新内容。
- 删除作物时关联数据处理正确。
- 非法图片格式不能上传。
- 普通用户不能执行管理操作。

### Git 节点

管理功能完成并经用户检查后提交第五阶段版本。

## 第六阶段：PDF 资料导入和数据质量处理

### 开发内容

- 逐页整理 PDF 内容。
- 录入作物基本资料、采集信息和检测数据。
- 整理图片文件并建立图片关联。
- 校对数字、小数和化学组分名称。
- 处理重复作物、别名和缺失值。
- 为每条资料保存来源页码。
- 通过管理员审核后发布数据。

### 验收标准

- PDF 资料结构化完成率达到目标。
- 关键字段经过人工校对。
- 图片和作物对应正确。
- 化学数据能够查询和筛选。

### Git 节点

数据导入脚本和校对结果检查后提交第六阶段版本。

## 第七阶段：AI 增强功能

### 开发内容

- 通过 DeepSeek SDK 接入 DeepSeek 服务。
- 管理员粘贴 OCR 文本后生成待审核字段建议，不自动写入作物资料。
- 基于已审核作物资料生成知识问答，并附 PDF 来源页。
- 保存问答记录、关联作物和来源页。

### 验收标准

- OCR 字段建议必须由管理员人工审核。
- 问答内容只使用已审核资料作为上下文，并保留来源页。
- 无匹配资料或服务异常时给出明确提示。
- API 密钥通过 Tomcat 环境变量配置，不进入源码或 Git。

### Git 节点

AI 功能经过效果检查后提交第七阶段版本。

## 第八阶段：测试、部署和交付

### 开发内容

- 完成功能、表单、权限和组合查询测试。
- 完成数据准确性、异常输入和图片上传测试。
- 部署到 Tomcat 或云服务器。
- 编写用户说明、部署说明、测试报告和课设报告。
- 准备项目演示和答辩流程。

### 验收标准

- 核心功能全部可用。
- 主要异常情况有明确提示。
- 项目可以独立部署运行。
- Git 工作区保持干净。

### Git 节点

完成最终检查后提交最终版本并创建 Git 标签。
