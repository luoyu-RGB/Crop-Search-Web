# 作物知识智能查找与匹配平台最终计划书

## 项目定位

将扫描版作物资料整理为可维护、可检索的结构化知识库，支持普通用户查询和管理员维护，并预留 OCR、AI 字段抽取、自然语言检索和资料问答能力。

## 用户角色

- 普通用户：注册、登录、按条件查询作物、查看详情和图片。
- 管理员：维护作物、别名、样品、检测数据和图片，审核待入库资料。

## 核心功能

1. 用户注册、登录、退出和权限控制。
2. 按中文名、英文名、拉丁学名、别名、科、属、特征、分布、栽培和用途查询。
3. 按含油率、碘值、酸值、皂化值和化学组分进行数值查询。
4. 支持全部条件或任意条件组合查询。
5. 支持选择查询结果字段、分页和详情展示。
6. 管理员增删改作物资料、图片、别名和检测数据。
7. 对 OCR/AI 提取内容进行人工审核后再发布。

## 资料处理流程

```text
扫描 PDF → OCR/人工转录 → AI 辅助字段抽取 → 人工校对
→ 临时数据 → 管理员审核 → 正式数据库
```

每条资料记录 PDF 来源页码；缺失数值保存为 `NULL`；图片保存为文件，数据库保存路径。

```text
users
crops

crop_oil_data
crop_components

```

## 技术路线

- 前端：HTML、CSS、JavaScript、jQuery、Bootstrap
- 后端：Java、JSP、Servlet、JavaBean、Filter、JDBC
- 数据库：MySQL
- 服务器：Tomcat
- 结构：JSP/HTML → Servlet → Service → DAO → MySQL

## 开发阶段

1. 产品调研、资料分析、PRD 和数据字典。
2. 数据库脚本、初始数据结构和 Java Web 项目骨架。
3. 用户注册、登录、Session 和权限 Filter。
4. 作物查询、组合查询、分页和详情页。
5. 管理员资料维护、图片和数据审核。
6. OCR/AI 增强能力、外部资料和自然语言查询。
7. 测试、部署、报告和演示材料。

## 目标指标

- 资料结构化完成率：100%。
- 关键字段校对准确率：95% 以上。
- 组合查询正确率：95% 以上。
- 普通查询响应时间：2 秒以内。
- 管理员录入时间降低：50% 以上。
